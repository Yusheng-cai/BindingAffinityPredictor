# Environments

Track environment specifications, lock files, and installation notes here. Actual environments and package caches remain outside the repository.

Use separate environments for Boltz-2, Nesso-1, and FlashBind/FlashAffinity unless compatibility is demonstrated. Record CUDA, driver, PyTorch, and optional kernel compatibility.

The resolved Boltz-2 environment is documented under `boltz-2.2.1/`.
