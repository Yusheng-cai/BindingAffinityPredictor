# 2026-W33 report code

This folder contains only the thin report build layer.

This report is currently a literature-grounded explanation of Nesso-1 and its
relationship to Boltz-2. It contains no experiment results or generated
figures.

Build from the repository root with:

    bash weeks/2026-W33/code/build_report.sh

The asset script snapshots the canonical bibliography and records its source
hash. It does not copy raw run artifacts.
